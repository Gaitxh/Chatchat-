Get started

  1. Click “+” to add a model. Choose a provider and approve access to that specific site when asked.
  2. Sign in normally if needed. Use the provider’s own browser tab in this profile. Enter your password only on the provider’s site.
  3. Use one dedicated new chat per seat, for every meeting. Keep personal chats separate. Each AI participates as an equal peer.

Local room, online providers

Meeting history is stored locally in this browser. Provider tabs stay online: proposals and shared discussion sent to them are handled under each provider’s policies. Local history does not delete provider chat history.

Preview status

This is a browser extension preview, not a signed desktop app. Provider compatibility still needs verification. Synthetic demos are separate from live meetings and do not prove provider support.

Find this help again

Open your browser’s Extensions → ChatChat → Details → Extension options. The ChatChat toolbar icon also opens or returns to your meeting room.

开始使用

  1. 点击“+”添加模型。选择服务商；需要权限时，只授权你选择的具体网站。
  2. 如需登录，按平常方式登录。使用当前浏览器配置中的服务商标签页，只在服务商网站输入密码。
  3. 每场会议的每个席位都使用一个专用的新对话。与个人聊天分开，每个 AI 都是平等参与者。

本地会议室，在线 AI 服务

会议历史保存在当前浏览器本地。服务商标签页仍需联网；发送给它们的议题和共享讨论受各自的数据政策约束。本地历史操作不会删除服务商的聊天记录。

预览状态

这是浏览器扩展构建预览，并非已签名的桌面应用。服务商兼容性仍需验证。合成演示与真实会议分开，不能证明服务商支持情况。

在浏览器中打开：扩展程序 → ChatChat → 详情 → 扩展程序选项。点击 ChatChat 工具栏图标也能打开或返回会议室。
