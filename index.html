本地使用，不需要开发环境

  1. 解压预构建安装包。打开包里的 START-HERE.html，将整个目录放在一个固定位置。无需安装 Node.js、Git 或 Rust。
  2. 手动加载扩展。在 Chrome 或 Edge 的扩展管理页打开开发者模式，选择“加载已解压的扩展程序”，选中包内 extension/ 目录。
  3. 打开独立会议窗口。固定 ChatChat 工具栏图标并点击它。使用已有模型登录所在的同一浏览器个人资料；不同个人资料的登录不会自动共享。
  4. 选择席位，再提问。用“＋”选择 AI 网站。未登录时在原网站正常登录；完成连接检查后，输入问题并开始协商。

这是需要手动加载的浏览器驱动预览版，不是已签名的原生桌面安装器，也不代表已经上架扩展商店。仅打开普通网页不能控制你的模型标签页。

“本地”指什么？

会议编排和历史保存在本机浏览器中；使用在线模型时，问题与必要的讨论上下文仍会发送给所选模型网站。ChatChat 不搬运浏览器 Cookie，也不要求你把网站密码输入到 ChatChat。

网站入口被识别，不等于已经通过真实收发验证。登录、站点权限、连接检查和真实协商验收是不同状态。

English installation and limits

Local consultation room — developer preview

This page is installation guidance, not a live meeting or simulated model conversation.

Extract the prebuilt package into a stable folder and open its START-HERE.html. In Chrome or Edge, enable Developer mode and load the included extension/ folder. Pin the ChatChat toolbar icon and open the meeting window. Choose your AI seats, sign in normally on each provider website when necessary, complete the connection checks, and submit a proposal.

End users do not need Node.js, Git, Rust, administrator rights, or a local web server. This preview still requires manual extension loading. It is not a signed native desktop installer or a published store listing.

Use the same browser profile as your existing AI logins. Local orchestration and history do not make online model inference offline: selected providers receive the proposal and relevant discussion. Site recognition is not proof of compatibility or readiness.
