# ChatChat Windows 桌面版

这是独立桌面多模型协商软件，不是浏览器扩展、PWA 或网页快捷方式。

## 安装与第一次使用

取得 `ChatChat-Setup-0.10.3-x64.exe` 后，双击即可安装到当前 Windows 用户目录并打开 ChatChat。安装包自带应用和完整浏览器运行环境，不要求 Node.js、Python、Git、API Key、Chrome 扩展或开发者模式。安装过程不下载额外运行环境；连接在线 AI 仍需网络。

在软件里点空席位的 **＋**，选择模型网站，在弹出的专用浏览器窗口登录。登录后软件自动检查页面，必要时可手动点“检查”。至少两个已就绪的不同来源入席后，在底部输入问题并开始讨论。上轮聊天不会直接当作新会议；新会议会创建新页面并检查空对话。

首次在本软件使用某个网站通常需要登录一次。本软件的登录配置与日常 Chrome/Edge 独立，不读取或复制日常浏览器的 Cookie。已登录的专用配置可以继续使用，除非网站要求重新登录或验证。

## 这份预览的范围

目标系统是 Windows 10/11 x64。当前打包产物是未签名的开发预览，不应当作已验收的正式发行版；Windows 可能显示未知发布者警告。不要关闭系统安全防护。正式发布仍需要发布者签名及干净 Windows 环境的安装、升级和卸载验收。

本版本提供独立桌面界面、环绕席位、底部提案、模型网站窗口、自动登录状态检查、受控多轮协商、停止、历史回放和 Markdown 导出。协议保留每个模型自己的最终立场与异议，不将多数同意等同于正确，也没有宣称实现了已经过全部模型复核的单一综合答案。

ChatGPT、Claude、DeepSeek、Qwen、Gemini 的自动连接配方是实验性的，尚无本轮真实账号端到端验收。网站变化、登录限制或网页结构不明确时会停止，不会假装就绪。MiniMax、小米 MiMo 和未知自定义网站目前允许打开作为待适配席位，但不能直接加入自动讨论；界面会明确标注。不能承诺任意网站都允许被第三方自动操作。

本版新增一条本机认证 HTTPS 出站通道，使用经验证的公网 IP 连接网站；发现内网跳转或浏览器文件损坏会直接阻止自动发送。对使用本机回调或特殊网络规则的网页，可能需要等待兼容适配，不能关闭安全保护强行连接。

详细安全边界和剩余限制：[Windows 桌面安全说明](SECURITY.zh-CN.md)。

## 可选的模型交叉复核答案（0.10.3 新增）

普通会议会像以前一样记录每位模型的完整最终立场，**不会自动额外扣除模型网站额度**。会议结束、至少两位真实参会模型仍然可用时，可以在中央「各方立场」页面**主动点击「生成复核答案」**。这项操作会在原会议的模型 Chat 中增加一次执笔请求和每位审查者各一次的复核请求；最多等于本次实际参加的模型数量，不能把普通会议结束视作已经自动产生「最佳答案」。

平台轮流选择一名原始参会模型起草面向用户的答案，必须引用至少两个不同模型的真实会议发言 ID。其余实际可用参会模型各自审查草稿；缺失引用、格式不正确、审查反对或超时，都不会被算成赞成。只有所有被邀请的审查者实际完成并赞成，才显示「全部审查通过（不等于事实正确）」；反对和失败始终保留。

点击引文可跳转至原始发言。综合草稿、审查意见与原始最终立场一起本地保存并可导出 Markdown。**历史回放、应用重启和取消操作不会重新发送综合答案请求**。软件意外关闭时会将未完成的复核标记为中断，原会议报告保持不变。网页账号是否支持该流程仍需真人登录后的提供方级验收。

## 本地会议备份与安全校验（0.10.3 新增）

现在打开「历史会议」即可点击 **「备份全部会议」**，手动选定文件位置，一次性导出所有已保存的有效会议、原始模型观点、复核草稿、审查回执，以及简单的席位书签。备份为明文 JSON，包含真实问题和模型回复等私人内容；**不包含**任何 Chromium 登录会话、Cookie、浏览器用户资料、模型授权资料或自动化操作日志。

导出文件带 SHA-256 完整性校验。点击 **「验证备份文件」** 可以只读检查文件是否完整及其中包含多少场会议；不会访问模型网站，不会覆盖或导入当前记录。超过大小上限或受损的会议归档不会被误报成成功的完整备份，用户仍可逐项导出有效会议。

**注意：当前版本尚未实现备份自动恢复。** 这项功能仅用于保存、检查和供后续受控恢复流程使用；安装、升级或卸载前请妥善保存备份文件。独立登录状态不包含在备份中，重装软件可能需要重新登录模型网站。

另外修复：会议结束后，用户只检查某个未就绪席位不会再关闭「生成复核答案」入口。重新打开、添加或移除席位等有可能改变实际聊天身份的操作仍会停止后续旧会话自动发送权限。

## 维护者：网络不稳定时的 Windows 离线打包

本功能仅用于**构建**，普通用户安装 ChatChat 时不需要 Electron 下载、npm 或环境变量。在 Windows 开发机已经通过可信软件包获得与当前锁定版本完全相同的 Electron ZIP 后，可使用：

PowerShell：
    $env:CHATCHAT_ELECTRON_DIST = 'C:\\本地缓存\\electron-v45.0.0-win32-x64.zip'
    npm run package:win

构建器只接受文件名、版本、Windows x64 架构和 SHA-256 均与项目锁定 Electron npm 包内 checksum 清单一致的压缩包。错误文件会被拒绝，不会绕过 Chromium 文件检查、ASAR 代码包完整性检查或 Windows 打包校验。未指定该变量时，CI 仍使用默认上游获取流程。

## 数据与控制

会议调度、记录和账号浏览器配置保存在本机应用目录。模型推理由所选网站处理，提案及讨论上下文会发送给它们。没有额外的 ChatChat 云端中转服务。

安装仅作用于当前用户，不修改浏览器企业策略。卸载默认保留账号配置和会议历史；重要会议可先导出。更新和修复前关闭 ChatChat。不要把应用数据目录整体发送给别人，其中可能含登录状态。

停止会阻断后续发送，已交给提供方的请求不保证能撤回。不确定某次发送是否成功时，不自动重复投递。退出会关闭软件管理的浏览器，不影响用户日常浏览器。

## 验证说明

已在 Windows 11 x64 的干净临时工作目录通过 121 项桌面自动化测试（含捆绑 Chromium、真实浏览器受控页面交互、会话锁定、历史异常隔离和取消边界），并由 Windows 原生工具链生成 NSIS 安装程序。**这不是实机安装／升级／卸载验收，也不是线上 Provider 回答测试。** 受控网页只用于验证界面、消息关联、隔离新会话、去重和取消等行为。

## 开发者构建

本节不是普通用户的安装步骤。开发者在仓库根目录准备依赖并编译 core，在 desktop 目录使用锁定的依赖和脚本。

```text
仓库根：npm ci
桌面目录：npm ci
桌面目录：npm test
桌面目录：npm run package:win
```

`package:win` 从固定 SHA256 资源构建自包含安装包；生产发布需要在安全凭据体系中配置签名。正式候选只使用 Windows 上的 electron-builder NSIS 打包路径，避免不同安装器产生重复的卸载项；Linux 上的交叉打包仅保留为历史研究证据，不作为分发方式。
