# Windows desktop harness implementation contract (2026-10-21)

TARGET: Real standalone Windows 10/11 x64 desktop app + one-click per-user Setup.exe. NOT extension, not PWA, no user Node/Python/Git, no developer mode, no API keys mandatory. Use Electron local-only UI + separately managed full Chromium via playwright-core; package browser at build time. Zero model windows on startup until user adds seats. Login inside normal managed browser windows. App-owned persistent profile per provider; never copy system browser cookies/default profile; new page/chat per meeting. No extensions, debug TCP listeners, auth bypass, stealth flags, or credential collection. Website may reject automation/login; stop honestly, never claim universal compatibility. Bundled browser must be sandboxed.

Folders OWNERS: renderer agent desktop/renderer/** + desktop/tests/renderer*.mjs. Runtime agent desktop/runtime/** + desktop/tests/runtime*.mjs. Controller agent desktop/main/controller.mjs + desktop/tests/controller*.mjs. Lead owns desktop/main/index.mjs + preload.cjs + package.json + build/installer + cross-component integration. Do not touch existing src/, extension, tests, root package config. Other agents are writing separate files: do not revert others or commit/push.

Use ESM .mjs, vanilla JS/HTML/CSS (no renderer build needed), strict CSP, textContent safe rendering. Node tests with node:test. Root compiled core at desktop/generated/src/** (lead builds it from existing repository, unchanged). In controller import CouncilOrchestrator and BrowserConsultationAgent from ../generated/src/core/orchestrator.js and ../generated/src/provider-sdk/consultation-agent.js relative to desktop/main is ../generated/src/... . Missing files at coding time okay.

Renderer bridge window.chatChat methods, all Promise returning state unless stated:
getState(); addSeat({providerId:string} OR {url:string}); openSeat(id:string); checkSeat(id:string); removeSeat(id:string); startMeeting({proposal:string,mode:'balanced'|'explore'|'decide'|'verify'|'stress_test',maxRounds:number}); stopMeeting(); newMeeting(); loadMeeting(id:string); exportMeeting(id:string): returns {saved:boolean}; openDataFolder(): returns {opened:boolean}; onState(callback): returns unsubscribe.

State shape: {version:'0.10.4',runtime:{available:boolean,label:string,message:string},providers:[{id,name,url,automation:'experimental'|'manual'}],seats:[{id,providerId,name,url,status:'opening'|'needs_login'|'ready'|'attention'|'closed'|'error',detail:string}],meeting:null|{id,proposal,status:'preparing'|'running'|'completed'|'cancelled'|'failed',phase:string,round:number,events:CouncilEvent[],report:null|CouncilReport,error?:string},history:[{id,proposal,status,updatedAt}],busy:boolean}. No raw credentials or page HTML in UI/history. UI displays remaining dissent and failed seats distinctly, never confidence as proof; final summary use actual core report positions, no fake synthetic content. Test/demo only explicit fixture in tests, not shipping live UI.

Runtime API export class ManagedBrowserRuntime with constructor({dataDir:string,executablePath?:string,onChange:(seat)=>void,headless?:boolean,chromium?:dependency-injected}). Methods getInfo(): sync runtime object; catalog(): sync provider list; list(): sync seat list; async addSeat(spec): seat; async openSeat(id): seat; async checkSeat(id): seat; async removeSeat(id); async prepareSeat(id,{sessionId,signal}): void; async send(id,{prompt,operationId,signal,timeoutMs}): {responseText,elapsedMs}; async stop(): void; async close(): void. Runtime state immutable copies. Runtime errors safe bounded. Runtime tests dependency injection, no credentials or real provider calls. Main creates runtime and controller, can set onChange later via closure. getInfo missing browser is honest unavailable, no shell/install command suggestion to user. Packaging will supply executablePath on Windows.

Runtime catalog HTTPS entries ChatGPT https://chatgpt.com/ ; Claude https://claude.ai/new ; DeepSeek https://chat.deepseek.com/ ; Qwen https://chat.qwen.ai/ ; Gemini https://gemini.google.com/app ; MiniMax https://chat.minimax.io/ (not proven auto support); Xiaomi MiMo https://mimo.xiaomi.com/ (not proven chat endpoint). Add arbitrary public HTTPS custom URL explicitly with manual status unless safely recognized. No speculative supported badges. Validate URLs no credentials, file/data/javascript, localhost, private IP; destination origin pinned. Pause automation on OAuth-origin pages; allow human login browser navigation without reading credentials. No network calls to model sites in tests.

Controller export createController({runtime,dataDir,onChange,version='0.10.4',core?:test injection}): methods same as renderer bridge excluding exportMeeting/openDataFolder (main owns save dialogs), getState sync; startMeeting returns state immediately and background task managed/cancelable; close() awaits cancellation. exportData(id) returns bounded Markdown string for main save dialog. Persistent app-owned atomically saved meetings/seats preferences; no secrets. Start with 2-8 ready seats, freeze roster, persist logs after phase/events. Completed history only replay not regeneration. At start new browser chats, then sealed first round/shared snapshots. Transport uses timeout and AbortSignal, no blind resend after ambiguous submission. stopMeeting no future sends and cancel callbacks fenced. Startup interrupted meetings marked interrupted/failed, never auto-replay. Strict validate proposal length and round bounds. Controller failure test must not require actual Chrome/Electron.

Security: main strict sender frame+origin IPC allowlist; renderer can't send paths/scripts, privileged browser control stays main. Remote model text is untrusted data. Never expose generic evaluate/fs/execute to renderer. No updater until signed release configured. Packaging unsigned internal preview must label limitations. Do not claim Windows runtime tested unless actually tested on Windows.
