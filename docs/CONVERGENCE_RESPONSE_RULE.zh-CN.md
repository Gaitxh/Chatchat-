# 收敛前回应规则

ChatChat 可以把“当前立场对齐度”作为公开讨论可以提前结束的信号，但**对齐度不是权威**。

## 规则

当所选 Proposal Mode 已经满足最低公开讨论深度后，只有同时满足下面两点，会议才可以提前收敛：

1. 各参与者最新立场达到该模式的收敛阈值；
2. 当前这一轮没有刚刚出现、仍值得让其他参与者看到并回应的新未决信号。

属于“新未决信号”的事件包括：

- `challenge`（质疑）
- `evidence`（证据）
- `revision`（立场/理由修正）
- `question`（追问）
- `uncertain`（明确的不确定性）

如果其中任意一种刚刚出现，并且该 Proposal Mode 的既有 `maxRounds` 里还剩下一轮公开讨论，ChatChat 就会保留下一轮，让其他 AI 在共享快照中真正看到这条新事件之后，会议才有资格进入最终立场阶段。

## 这不意味着什么

这**不是无限辩论**。Proposal Mode 的节奏上限仍然是硬边界。如果已经没有公开讨论轮次可用，即使最后一轮刚出现新信号，会议也会继续进入最终立场。

`support`、`defense`、`concede` 本身不会自动强制再开一轮；它们仍然完整留在公开记录里，并会在后续仍存在讨论轮次时影响参与者回应。

## 为什么

75% 或 90% 的对齐度，不应该在一个重要反例、新证据或公开改口刚出现的同一瞬间就把会议“关掉”。多数意见只是需要检验的信息，不是一个隐形议长用来宣布散会的权力。
