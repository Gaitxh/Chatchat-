# ChatChat current product map

The README now describes four distinct layers that must not be collapsed into one another:

1. Blackboard events — public structured contributions.
2. Conflict Board / Resolution Ledger — structural dispute threads and exact response obligations.
3. Explicit Stance Fronts — thread-local CURRENT / VACATED positions based only on participant-authored stance-bearing events.
4. Final Position Floor — meeting-wide report seat accounting, paired with Provider Final execution provenance.

Final report seats distinguish `provider_final`, `fallback_placeholder`, and `unverified_record`. A fallback placeholder remains in report accounting but is not presented as a Provider-authored Final judgment.

Browser evidence uses same-session Chrome DevTools Protocol capture: wait for the product marker, wait for paint, freeze PNG + DOM from the same page, reject visually blank PNGs, then validate semantic markers.
