## 实际独立 Agent 执行

实际启动 10 个独立 Codex 任务：第一轮 3 个只读审查、5 个按文件范围隔离的实现任务、第二轮 2 个只读复审。使用 `gpt-6.1-sol` xhigh / max 和 `gpt-6-astra` xhigh / max。8 个任务正常结束并提交结论；分发、席位隔离两个实现任务达到执行时限，未提交完整结论，其代码由主执行者接手并纳入后续复审、修改和回归。没有把同一回复中的角色扮演计作独立 Agent。

记录只保留任务、模型、努力等级、退出状态与结论是否存在；不提交内部思考、原始会话、凭据或机器用户名。机器可读证据见 [local-preview-20261021.json](validation/local-preview-20261021.json)。

## 已落实的修订

| 发现的问题 | 修订与证据 |
| --- | --- |
| 普通用户必须装 Git/Node 才能获得可加载扩展 | 预构建 ZIP，内含 `extension/` 和双语离线 `START-HERE.html`；完整性校验与版本元数据；6 项打包测试 |
| Toolbar/窗口入口不统一、可能重复打开 | 独立 popup 会议窗口，复用已有真实会议，排除演示和相似路径；26 项窗口/欢迎页测试与实际安装测试 |
| 起步团队替用户作选择 | 空会议室显示添加席位，建议团队仅由用户主动启用；安装不打开提供方网站，不预授权域名 |
| 从已发现标签页加入会向旧私人聊天发握手 | 发现只提供来源建议；新建独立管理的标签页；自定义入口须确认；重复席位和失败创建清理测试 |
| Qwen 域名别名可能重复入席或授权错误域名 | 按实际目的域名归一化、去重和计算授权 |
| 发送按钮全页猜测会点中无关的 Send newsletter | 正式发送与自动连接共同校验 composer/send 的唯一性、可编辑性、可见性、启用状态和作用区域；不操作密码输入框 |
| 页面跳到另一来源后仍以旧席位身份发送 | 注入与发送前核验管理席位，消息携带预期来源；接收端执行及排队执行时再次核验 |
| 输入回显或历史 READY 会被当成自动连接成功 | 自动连接只接受新增、具有明确助手身份标记的回复；失败不以全页文本猜测成功 |
| 发送回执不确定后继续自动重发 | 已有配方发送失败不再悄悄退回另一轮自动 setup；超时截断不得成为已完成回答 |
| 全部提供方失败却显示 100% 一致 | 运行时失败来源与模型观点分离；报告、实时读数和新格式最终席位图排除失败票，保留完整席位分母与可见失败记录 |
| 不相关的高置信度改口消除所有不确定项 | 只有引用该条具体不确定事件的自身 revision 才能关闭；更新对应的上下文/记忆回归夹具 |
| 共享事件可被一个席位或回调修改 | 输入复制、嵌套冻结、不可变公开快照及回调隔离测试 |
| 普通网页默认变成合成演示 | 普通入口改为静态双语安装页；演示必须显式进入，继续保留 synthetic/live 边界 |

第二轮复审实际复现了自动 setup 绕过发送安全校验、来源校验过期、实时读数仍统计失败占位三个问题。上述修订覆盖这些发现，并新增负例；不是简单接受第一轮“测试通过”。

## 已运行的验收

- `npm run check`：通过类型检查和产品边界检查。
- `npm test`：65 个确定性测试程序通过；其中 DOM 安全 66 项、窗口与欢迎页 26 项、打包 6 项。
- `npm run build:web`、`npm run build:extension`：生产构建通过。存在 Vite 大 chunk 提醒，未将其误报为失败或已优化。
- Chrome 153.0.8010.36：在全新临时个人资料中实际加载生产扩展；首次欢迎页、真实 popup、重复按钮复用、空室邀请入口、安装无提供方权限、不开外部模型页面、无未捕获异常共 8 项通过。测试后关闭浏览器并清理临时个人资料。
- 已知和自定义网站邀请流程：在同一实际浏览器内用明确标识的合成夹具通过，包括自定义新会话入口确认；这不证明任何在线模型实际生成回答。
- ZIP 生成及重算校验通过；出包前重新构建，避免源码与旧产物混用。

复现安装层测试：`node scripts/smoke-installed-extension.mjs dist-extension artifacts/installed-extension`。需要支持相应 DevTools 扩展命令的桌面 Chrome；可用 `CHROME_BIN` 指定路径。该脚本只操作专用临时浏览器，不连接用户的已有个人资料。

本次不是最终独立原生应用：没有 Windows/macOS 签名安装器、商店分发或自动更新，仍需手动加载扩展。Linux Chrome 安装验收不能外推到 Edge、Windows 或 macOS。

没有登录真实模型账号，没有运行真实提供方协商，不能宣称 DeepSeek/Qwen/MiniMax/Xiaomi/ChatGPT/Claude 等全部已兼容。自动助手区域识别是保守的；没有明确身份标记的网站需要人工教学适配。新标签页、新对话入口和连接握手仍不等于经过验收的无旧上下文新 Chat。

完整环绕席位视觉重排、同行复核式最终答案合成等大改造不在本次已完成范围。应先用 [真实提供方验收清单](MANUAL_PROVIDER_TEST.md)证明最小两提供方闭环，再扩大正式支持名单。严格区分“实际安装通过”“合成 UI 通过”和“真实推理通过”。
