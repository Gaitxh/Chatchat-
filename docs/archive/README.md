# Archived ChatChat Experiments

This directory preserves ideas and product language from earlier ChatChat generations.

They are useful history, but they are **not the current product contract**.

Current ChatChat terminology:

- User Proposal / 用户提案
- equal AI participants / 平等 AI 参与者
- sealed first round / 密封第一轮
- shared Blackboard / 共享协商板
- Consultation Theater / 协商剧场
- Consultation History / 协商记录

Archived terminology such as `King`, `Royal`, `House`, `Court`, `Chairman`, and older `Council` product metaphors should not be reintroduced into the primary browser UI unless the product direction explicitly changes again.

The active documentation index is [`../README.md`](../README.md).
