Install in Chrome or Edge

You need a desktop Chrome or Edge browser and your own provider accounts. You do not need Node, Git, Rust, or a terminal. This page works offline; live AI consultations need the internet.

  1. Unzip everything to a stable folder. Keep this guide, extension/ and the other files together. Avoid temporary folders. Do not try to load the ZIP itself.
  2. Open the extension manager. In the browser profile you use for AI websites, paste chrome://extensions (Chrome) or edge://extensions (Edge) into the address bar. Turn on Developer mode, choose Load unpacked, and select the extracted extension/ folder containing manifest.json.
  3. Pin ChatChat. Open the browser’s Extensions menu (puzzle icon), pin ChatChat, then click its icon to open the consultation room. The room is a browser-backed standalone window; Chrome/Edge still supplies its runtime and profile.
  4. Choose seats and sign in yourself. Choose the AI sources you want as equal participants. Sign in on each provider’s own website in the same browser profile. Give explicit site permission only to origins you choose when ChatChat asks. Account sign-in, site permission and connection readiness are separate steps; a recognized logo or open tab proves none of them.
  5. Send one proposal. Use fresh provider chats for each meeting; existing private conversations are not meeting inputs. Check each seat’s connection state, resolve any requested manual login or connection step, then send your proposal. Choose at least two distinct AI sources for a peer consultation. Each source has equal standing; there is no privileged chair.

What “local” means

ChatChat coordinates the meeting and keeps its history locally in this browser profile. The chosen AI websites receive prompts and perform cloud inference under their own terms. This package does not provide offline AI models or provider accounts. Arbitrary websites are not guaranteed to work; recognition, a taught recipe and synthetic demos do not prove live compatibility.

Keep synthetic demonstration sessions separate from live provider sessions. A demo, packaging check or successful window launch is not evidence of a signed-in or ready provider.

Update, back up, or remove

Export important meeting records before updating or uninstalling. Use the room’s available record/receipt export or copy controls and save the result yourself. Export is a record, not a promise of full restore. History belongs to the current browser profile and extension ID; it is not an automatic backup.

Close ChatChat meeting windows and keep the extension installed. Replace the contents of the existing extension/ folder with the new version, remove obsolete files, and click Reload in the extension manager. Keep the same folder path and browser profile to preserve the unpacked extension ID and its associated history. A different path/profile or removing and reinstalling can lose that continuity.

To remove it, export first, then use Remove in the extension manager. If Developer mode or Load unpacked is unavailable on a managed browser, ask your administrator or wait for store distribution. This package does not change enterprise policies or silently install anything.

在 Chrome 或 Edge 中安装

需要桌面版 Chrome 或 Edge，以及你自己的 AI 网站账号。无需 Node、Git、Rust 或命令行。本指南可离线阅读；真实 AI 协商需要联网。

  1. 将整个压缩包解压到固定目录。保留本指南、extension/ 和其他文件。不要放在临时目录，也不要直接加载 ZIP。
  2. 打开扩展管理页面。在你登录 AI 网站的同一浏览器个人资料中，在地址栏输入 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions。打开开发者模式，选择加载已解压的扩展程序，选择解压后包含 manifest.json 的 extension/ 文件夹。
  3. 固定 ChatChat 图标。打开浏览器的扩展菜单（拼图图标），固定 ChatChat，点击图标打开协商室。独立协商窗口由浏览器承载，仍依赖 Chrome/Edge 及当前个人资料。
  4. 选择席位并自行登录。选择要平等参与的 AI 来源，在同一浏览器个人资料中打开各提供方网站并亲自登录。仅在 ChatChat 请求时，明确授权你选择的网站。账号登录、站点权限和连接就绪是不同状态；识别到图标或打开标签页不代表已完成任何一项。
  5. 发送一个提案。每场会议使用新的提供方聊天，不把已有私人会话作为会议输入。确认各席位连接状态，完成界面要求的手动登录或连接步骤，再发送提案。平等协商至少选择两个不同 AI 来源；每个来源地位相同，没有特权主持人。

“本地”的含义

ChatChat 在本地协调会议，并在当前浏览器个人资料中保存历史。选中的 AI 网站会收到提示词，并按各自条款在云端推理。本包不包含离线模型或 AI 账号。不保证任意网站都可用；识别网站、教学配方或合成演示均不能证明真实兼容性。

合成演示与真实提供方会话应保持分离。演示、打包检查或成功打开窗口，都不能证明提供方已经登录或就绪。

更新、备份与卸载

更新或卸载前，先导出重要会议记录。使用协商室当前提供的记录、回执导出或复制功能，自行保存文件。导出的记录不等于完整恢复能力。历史与当前浏览器个人资料及扩展 ID 关联，不是自动备份。

关闭 ChatChat 会议窗口，保留已安装的扩展。将新版本文件替换到原来同一路径的 extension/ 文件夹中，清除旧版多余文件，然后在扩展管理页面点击重新加载。使用同一文件夹路径和浏览器个人资料，才能保留已解压扩展 ID 及其关联历史；移动目录、更换个人资料或卸载重装可能导致历史无法延续。

卸载时，先导出，再在扩展管理页面选择移除。如果受管理浏览器禁用了开发者模式或加载已解压扩展，请联系管理员或等待商店发行。本包不会更改企业策略，也不会静默安装。
